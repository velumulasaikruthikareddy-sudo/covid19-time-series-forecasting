# COVID-19 Time Series Forecasting Project

## Description

This project analyzes and forecasts COVID-19 trends using Data Analytics and Machine Learning techniques. It provides visualizations, trend analysis, and forecasting based on historical COVID-19 data.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Streamlit
* Scikit-learn

## Features

- COVID-19 Data Analysis
- Time Series Forecasting
- Interactive Dashboard
- Trend Visualization
- Future Case Prediction
- Data Analytics Reports

## Project Structure

* app.py — Main application
* modules/ — Data processing and forecasting modules
* requirements.txt — Required Python libraries
* dataset/ — Dataset folder

## Dataset Notice

This project uses:

- covid_data.csv
- owid-covid-data.csv

The datasets are not included due to GitHub file size limitations.

To run this project:

1. Download the COVID-19 dataset.
2. Place the dataset file inside the `dataset` folder.
3. Install dependencies using:

   ```
   pip install -r requirements.txt
   ```
4. Run:

   ```
   streamlit run app.py
   ```
